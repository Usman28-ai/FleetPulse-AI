1. Project Title & Overview

FleetPulse AI answers a practical logistics question: Where should a fleet allocate the next operational and fuel budget across City Van, Intercity Truck, Cold Chain, Last-Mile Bike, and Warehouse Shuttle?

The studio turns route and trip history into weighted delivery KPIs, trains an XGBoost revenue model with a chronological train/validation/holdout split, benchmarks Pandas vs MapReduce vs Apache Spark from 10K to 10M rows, and splits a user-entered PKR budget exactly to the last paisa under optional channel caps. The core objective is transparent, reproducible decision support—not live telematics or payment integrations.

2. System Architecture & Data Flow

FleetPulse uses a decoupled client–server design in which FastAPI is the single source of numeric truth and Next.js is the Ops Control Room UI.

Browser → Next.js 16 Ops Control Room (UI) → FastAPI (numeric truth) → SQLite catalog + Parquet
LayerResponsibility
Next.js frontendScreens, filters, charts, formatting (paisa → PKR); never recomputes KPIs, predictions, or allocations
FastAPI backendAnalytics, ML, optimization, benchmarks, and commerce—all authoritative numerics
StorageSQLite workspace catalog; Parquet datasets under the data directory

Long jobs (training, benchmarks) run as server workers that the UI polls. Analytics are paged server-side so the browser never receives multi-million-row payloads.

5. Results & Outcomes

  • ML quality: On the seed 10K workflow, accepted XGBoost beat baseline (holdout RMSE ≈ 7,195 vs ≈ 10,416), with identical re-evaluation after reload.
  • Budget integrity: A PKR 1,000,000 plan totals exactly Rs 1,000,000.00 in integer paisa; channel caps (e.g. Google ≤ 20%) are enforced without breaking the exact sum.
  • Scale evidence: All three engines ran across four scales with repeat parity; 10M-row generation and benchmarks completed on a single machine.
  • Commerce: Demo and UI CSV flows reconcile net sales and matched costs with zero reference drift on pilot fixtures.
  • Verification: Pytest, TypeScript/ESLint, browser QA, and E2E journeys confirm UI numbers match the API.

Bottom line: FleetPulse AI demonstrates an end-to-end big-data analytics studio—data → KPIs → model → exact budget split—where FastAPI owns every numeric result and Next.js presents an Ops Control Room ready for academic demo and GitHub submission.
